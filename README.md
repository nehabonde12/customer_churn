
Customer Churn Analysis Dashboard

Skills: Power BI | DAX | Pandas | Data Analysis

Description:

Analyzed 20,000 customer records using Power BI to identify customer churn patterns and key contributing factors.

• Identified an overall churn rate of 34.2%

• Found 43.2% churn among month-to-month contract customers

• Identified 41.4% churn among customers without tech support

• Converted findings into 4 actionable customer-retention strategies

Tools: Power BI, DAX, Pandas
